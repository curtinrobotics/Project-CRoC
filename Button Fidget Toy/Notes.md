# Button Depress Types
## Style
Changes how the button feels on the way down
- Linear
- Tactile
- Clicky
## Force
The amount of force required to actuate the switch
- 45 cN
- 55 cN
- 60 cN
# Button Shapes
## Mounts
How the key cap mounts to the button
- Cross (most common)
- Enclosed cross
- Box
- Lo Pro (not common)
- Alps (not common)
## Body Shape
MX seems to be the most common
